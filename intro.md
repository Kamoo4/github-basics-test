What I have learned thusfar is that Git is a version control system, and Github is a web-based platform which is used to save Git repositories.
I learnt that we are able to make our repository public or private, we can also invite people to become collaborators.
We can use GitHub to have discussions with fellow team members. All collaborators are also able to make changes in the repository. 
I have also learnt that we can always go back to the previous versions of our repository if mistakes were done on the changes that were made. Each contributor is also able to request a pull
request, which will assist in merging the changes they have done in their branch with the main branch. We use the commit command to make changes to our repository, and we can also
use git help if we need any assistance while working on the repository.
